# User request: keep a crash log for easier error reporting

Gabriel asked for logs and then Arch installation guidance. The existing `start-app-arch.sh` already wrote `launcher.log` for GUI launches only, overwriting every run and losing terminal failures. `tools/start_app.py` printed exceptions without a persistent crash file. The Docker application recorded engine output but silently swallowed some controller monitoring failures.

This branch implements:
- **Arch**: always append launcher stdout/stderr (terminal and KDE), write UTC start/exit records, rotate 1 MB + three backups, chmod 0600, refuse symlink destinations, show the path on failure. New tests check repeated launches, rotation and symlink denial.
- **Python startup**: `tools/start_app.py` emits private rotating `crash.log` with exception type, message and bounded stack frames without source lines or environment dumps. Account IDs and common credential assignments are masked; logs are not uploaded.
- **Docker UI**: `src/lab/app.py` records monitor, HTTP and server exceptions into `results/app/app-crash.log`, preserving the existing pause/stop fail-closed behavior. Existing engine output remains in `results/app/engine.log`.
- **Windows**: `tools/launch_windows.ps1` records pre-Python errors (including dangling interpreter registrations) into `%LOCALAPPDATA%\TradingLab\logs\launcher.log`, while Python errors go to `crash.log`. Native PowerShell CI checks account/password masking.
- README and `docs/arch-install.md` list exact log locations, commands and warning to review logs before sharing. No credentials, files or logs automatically leave the machine.

**Safety limitations:** Some upstream Docker/IBKR output can contain private details that pattern-masking does not recognize. Logs are 0600 on Linux and should be reviewed before sending. Crash records aid diagnosis; they are not a replacement for broker reconciliation or a qualified crash-recovery path. Neither live-account trading nor new broker permissions were enabled.

**Validation:** previous full branch commit `bb36fde` CI passed all jobs at https://github.com/gahitchi/trading/actions/runs/40131939003. The logging changes have passing Windows-native smoke, lint, package, Docker and collaboration jobs in https://github.com/gahitchi/trading/actions/runs/40133401416; Python fast, harness and offline checks were **still running** when this proposal was written. Please independently review the Python 3.13/3.14 matrix and scrutinize confidential-information leakage before integrating to main.
