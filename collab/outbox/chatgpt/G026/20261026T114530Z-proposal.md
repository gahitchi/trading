## Proposed source change

Branch: `chatgpt/corporate-action-ledger-20261026`, descended from the user-accepted `chatgpt/termux-offline-20261026`.

Root cause FP-01/F-R09: prior backtests fabricated post-delisting bars and volume, which the parent branch now properly rejects. F1 still lacks a *genuine* financial settlement event.

This proposal adds **the independent corporate-action financial reference** without pretending it is a Nautilus position/account transition. New `src/lab/markets/corporate_actions.py` distinguishes effective date and source availability, signed historical basis and accrued receivables/payables, zero-recovery bankruptcy, short cash liabilities, future actual cash receipts and precision/duplicate safeguards. It rejects open or unconfirmed GTC orders, ambiguous broker quantity/version evidence, fractions requiring cash-in-lieu and anything in a future source. `src/lab/markets/corporate_journal.py` reuses the hash-chained, append-only `EventJournal` with separately classified `corporate_action` and `corporate_cash` events, durable append-before-ack, replayed deterministic state digests, and recovery of pending obligations after restart. It refuses foreign ordinary fill events and changed initial-book assumptions. This component **cannot connect to a venue or mutate `ExecutionAgent.cash` or Nautilus Account/Cache/Portfolio**. Existing backtest delisting safeguard remains unchanged.

Portable `unittest` suites `tests/test_portable_corporate_actions.py` and `tests/test_portable_corporate_journal.py` exercise zero cash, long/short settlements, partial receipt, duplicate conflict, GTC/version freeze, time availability, fractional entitlements, wrong currency, changed book, post-append crash replay, tampering and Python `-S` no-site-packages imports. The same suite is discoverable by `lab.mobile check` on Termux and by hosted pytest. Operator actual Android tests for *previous* offline branch were 23/23 passing; the new corpus has **not** yet been independently run on-device.

Document: `docs/architecture/corporate-action-financial-protocol.md` gives accounting identities and explicit native parity requirements. Official Nautilus docs identify a non-fill `InstrumentClose` expiration path **only for live binary-option positions**, while backtest/sandbox expiration matching still uses fills; `PositionAdjusted` does not imply an unrestricted cash-merger API.
