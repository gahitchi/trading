## New independent-code implementation for review

Branch `chatgpt/broker-reconciliation-oracle-20261026`, descended from that operator-tested code. Added `src/lab/kernel/broker_reconciliation.py`: no Nautilus, broker SDK, sockets, credentials or scientific dependencies. Accepts a typed, immutable **reported, unverified** broker snapshot with account namespace, instrument/version, source digest, as-of and availability bounds, claimed completeness flags, reported positions and complete order/execution records. Compares it against the independent OMS persisted journal and projected positions/fills, detecting stale/local-corrupt journals, version/clock mismatch, missing or unexpected broker orders/executions, exec ID/quantity/order ownership conflicts, missing coverage and pending cancel or unknown results. Returns sorted findings. **Does not write any session state or release a reservation.**

Important security hardening: the result's `source_authenticated`, `broker_authorization` and `release_reservations` are **hard-coded read-only False properties**, not caller-overridable dataclass flags. An internally consistent reported snapshot is *not* authenticated custody or causal ordering; source SHA-256 and completeness flags are only source claims. A real broker adapter must separately prove identity, account scope, complete sequencing/cursors, execution order history and margin/cash before any authorization. No real money.

Additional defect corrected in `src/lab/kernel/order_lifecycle.py`: the previous early idempotent `_post` return bypassed the SQLite head-check if another process appended events. This could return old success to a stale actor. Now every path checks the committed journal-head digest before any duplicate short-circuit. A dedicated multi-session regression test locks down this behavior.

New `tests/test_portable_broker_reconciliation.py` contains 16 synthetic/adversarial test cases, and prior order lifecycle suite gains one stale-duplicate regression (expected 97 portable tests total). Both test types run without site-packages/Naulitus. `docs/architecture/independent-broker-reconciliation.md` defines scope and limitations.
