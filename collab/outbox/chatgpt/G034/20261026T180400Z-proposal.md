## Proposal (strictly offline, no broker authority)

Branch: chatgpt/payload-bound-source-20261026.
Feature checkpoint: 131527295003f0c93c01779e29e82d1b57308b52.
Parent branch: chatgpt/causal-fence-identity-20261026 at b8c5f473.

The source fence previously committed only to opaque SHA-256 payload digests.
A caller could supply a correctly chained set of source frame digests that did
not decode to the report's exact order, execution or position contents.

New lab.kernel.source_payloads requires a bounded immutable canonical JSON
payload per claimed frame, compares the digest to the frame, strictly decodes
Decimal quantities and nanosecond timestamps, and reconstructs snapshot
orders, executions and position for exact comparison. Missing payloads,
altered bytes, extra executions, wrong final position, duplicate IDs and
execution timestamp inconsistency produce hard findings. Partial incremental
streams without proven complete predecessor state are explicitly rejected by
SOURCE_PAYLOAD_REPLAY_NOT_FROM_GENESIS.

No broker SDK, network, credential, dispatch, strategy approval, reserve release
or external source authentication was introduced. Paper/live sources are still
categorically refused by the preexisting fence. All three authority flags
remain False, including on fully consistent self-asserted data.

Adversarial offline tests: tests/test_portable_source_payloads.py (14 cases).
Documentation: docs/architecture/offline-source-payload-binding.md.
