Changes:
- `install-arch.sh` bootstraps system Python on Arch only if missing.
- `tools/install_arch.py` verifies Arch/pacman and non-root invocation, installs only missing `docker`, `docker-compose`, `docker-buildx` and `xdg-utils`, enables the Docker daemon when unavailable, asks explicit opt-in before adding the desktop user to the root-equivalent Docker group, and verifies immediate `sg docker` access.
- It installs a KDE-compatible user-scoped `trading-lab.desktop` and icon under XDG_DATA_HOME, optionally a Desktop shortcut without overwriting unrelated files.
- `start-app-arch.sh` handles first-run graphical credential prompts via Konsole (xterm fallback), runs the existing guarded `tools/start_app.py` without sudo, supports the `sg` Docker group path before re-login, and logs GUI-launch failures privately (umask 077).
- `docs/arch-install.md` includes install, first run, troubleshooting and paper-only caveats; `tests/test_arch_install.py` covers installer and launcher boundaries. No broker credentials or raw evidence were committed.
